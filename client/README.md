# VTS (Volunteer Tracking System) Client

This directory contains the front-end application for the Volunteer Tracking System (VTS), built with React 19, TypeScript, Tailwind CSS, and Vite.

For the complete project documentation, including:
- Project overview and volunteer journey
- Roles, permissions matrix, and rank promotion thresholds
- Complete functional requirements status (FR IDs)
- Data model and entities specification
- Demo accounts and 8-step evaluation script
- Express, Supabase, Cloudinary, and Brevo backend integration mapping
- Design tokens and component architecture

Please refer to the main repository documentation:
**[View Root README.md](../README.md)**

---

### Quick Start

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Run production build and type check
npm run build
```
