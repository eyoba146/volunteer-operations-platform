# VTS (Volunteer Tracking System) Client

This directory contains the front-end application for the Volunteer Tracking System (VTS), built with React 19, TypeScript, Tailwind CSS, and Vite.

For the complete project documentation, including:
- 1. Overview and target user groups
- 2. Key concepts (role, rank, permission, scope, workspace, module)
- 3. Four-tier organization structure and access scope hierarchy
- 4. Complete role workspaces and screen architecture
- 5. The 9-stage volunteer lifecycle and workflow diagrams
- 6. Rank promotion thresholds, evidence summaries, and certificates
- 7. Money in (Telebirr registration fee) and money out (field allowances) flows
- 8. Permission matrix, four-eye principle, and backend security invariants
- 9. Multi-channel notifications (In-app, Brevo email, SMS 8080) and reports
- 10. Complete data model with entity-relationship diagrams
- 11. Backend architecture: Express routes, Supabase tables, and third-party integrations
- 12. Local development guide, demo accounts table, and evaluation demo script
- 13. Comprehensive requirements traceability matrix (all FR IDs)
- 14. Product roadmap beyond prototype
- 15. Operational assumptions and client open questions

**[View Root README.md](../README.md)**

```bash
# Install dependencies

# Start local development server
npm run dev

# Run automated tests and build verification
npm run build
```
